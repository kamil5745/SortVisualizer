# Шаблоны визуализации SortVisualizer
Каждый шаг алгоритма: полная очистка экрана + новый кадр.
Цель: глазами видно, как меняется последовательность чисел (поэтапно, без лимитов на вывод).
---
## 1. Quick Sort (Хоар)
Должны быть видны: индексы, массив, `[L]` / `[R]`, Pivot, текст шага.
### Кадр: сканирование
========================================================================
 [Быстрая сортировка] Опорный элемент (Pivot) = 6
========================================================================
 Индексы:  0  1  2  3  4  5  6  7
 Массив:   3  9  2  6  8  1  7  5
                [L]          [R]
 -> Сканирование: L ищет элемент >= 6, R ищет элемент <= 6...
------------------------------------------------------------------------
### Кадр: обмен
========================================================================
 [Быстрая сортировка] Опорный элемент (Pivot) = 6
========================================================================
 Индексы:  0  1  2  3  4  5  6  7
 Массив:   3  9  2  6  8  1  7  5
                [L]          [R]
 -> НАЙДЕНО: Элемент 9 >= 6 и Элемент 1 <= 6. Выполняется ОБМЕН (9 <-> 1)!
------------------------------------------------------------------------

## 2. Merge Sort
Каждый кадр содержит 4 блока:
1. Индикатор рекурсии (деление/слияние + глубина `>>`)
2. Зона основного массива (границы подмассивов + `[L]` / `[R]`)
3. Зона временного буфера (`_` = пусто)
4. Текстовый лог шага
### Этап 1: Разделение
========================================================================
 [Сортировка слиянием] РАЗДЕЛЕНИЕ МАССИВА
 Глубина рекурсии: >> >> (Уровень 2)
========================================================================
 Текущее состояние задачи:
 Активный диапазон: индексы [0..3]
 [ 3, 8, 2, 5 ]
 -> Разделение по центру (индекс 1)
 Результат деления:
 Левая часть:  [ 3, 8 ]
 Правая часть: [ 2, 5 ]
 -> Задача разбита на две подзадачи. Переход к левой части...
------------------------------------------------------------------------
### Этап 2: Слияние — кадр А
========================================================================
 [Сортировка слиянием] СЛИЯНИЕ ПОДМАССИВОВ [0..1] и [2..3]
 Глубина рекурсии: >> (Уровень 1)
========================================================================
 ИСХОДНЫЕ ПОДМАССИВЫ (в основном массиве):
 Индексы:  0   1  |  2   3
 Данные:  [3]  8  | [2]  5
           ^         ^
          [L]       [R]
 ВРЕМЕННЫЙ БУФЕР (Выделенная память O(N)):
 Индексы:  0  1  2  3
 Буфер:   [2, _, _, _]
 -> Логика: Сравниваем элементы под указателями: 3 > 2.
 -> Результат: Элемент 2 меньше, копируем его в буфер на позицию 0.
 -> Действие: Указатель [R] смещается вправо на индекс 3.
------------------------------------------------------------------------
### Этап 2: Слияние — кадр Б
========================================================================
 [Сортировка слиянием] СЛИЯНИЕ ПОДМАССИВОВ [0..1] и [2..3]
 Глубина рекурсии: >> (Уровень 1)
========================================================================
 ИСХОДНЫЕ ПОДМАССИВЫ (в основном массиве):
 Индексы:  0   1  |  2   3
 Данные:  [3]  8  |  2  [5]
           ^             ^
          [L]           [R]
 ВРЕМЕННЫЙ БУФЕР (Выделенная память O(N)):
 Индексы:  0  1  2  3
 Буфер:   [2, 3, _, _]
 -> Логика: Сравниваем элементы под указателями: 3 < 5.
 -> Результат: Элемент 3 меньше, копируем его в буфер на позицию 1.
 -> Действие: Указатель [L] смещается вправо на индекс 1.
------------------------------------------------------------------------
### Этап 3: Перезапись из буфера
========================================================================
 [Сортировка слиянием] СИНХРОНИЗАЦИЯ С ОСНОВНЫМ МАССИВОМ
========================================================================
 МАССИВ ДО ОБНОВЛЕНИЯ:     [ 3, 8, 2, 5 ]
 ВРЕМЕННЫЙ БУФЕР:         [ 2, 3, 5, 8 ]
 ===========> Перезапись области [0..3]
 МАССИВ ПОСЛЕ ОБНОВЛЕНИЯ: [ 2, 3, 5, 8 ]
 -> Подмассив [0..3] успешно отсортирован и возвращен в основную память.
------------------------------------------------------------------------
### Метрики Merge Sort
- Сравнения: только когда сравниваются элемент слева и элемент справа (L vs R).
  Проверки выхода указателей за границы НЕ считать.
- Перестановки/записи: каждая запись из массива в буфер + каждая запись из буфера обратно в массив.

## 3. Heap Sort
Массив показывать как текстовое дерево. Нарушение кучи помечать `*(x)*` или стрелкой.
========================================================================
 [Пирамидальная сортировка] Просеивание элемента вниз (Heapify)
========================================================================
 Текущее состояние двоичной кучи:
           *(3)*  <-- Нарушение (родитель меньше потомков)
          /     \
       (12)     (9)
       /  \     /
     (7)  (4) (2)
 -> Родитель (3) меньше своего максимального потомка (12).
 -> Выполняется обмен элементов местами.
------------------------------------------------------------------------

## 4–6. Bubble / Insertion / Selection
Шаблона в ссылке нет — тот же стиль, что Quick:
- индексы
- текущий массив (чтобы было видно изменение последовательности)
- указатели на активные позиции (i, j, min, key и т.п.)
- текст шага (сравнение / обмен / сдвиг)
Пример каркаса кадра:
========================================================================
 [Пузырьковая сортировка] Проход i=0, сравнение j=2 и j=3
========================================================================
 Индексы:  0  1  2  3  4  5
 Массив:   5  1  4  2  8  0
                 [j][j+1]
 -> Сравнение: 4 > 2. Выполняется ОБМЕН.
------------------------------------------------------------------------
